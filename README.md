## Mima / 魅魔

Mima character mod.

魅魔角色模組。

## Btw / 但又話說回來了

After transitioning from v1 Mima to v2, she now provides a relatively more proper power scaling experience, and is available now.

經過初代魅魔的洗禮後，二代魅魔對比下終於擁有對比下符合正常的強度遞增體驗，可供玩家體驗了。

## Includes / 內含

- Character Cards: 73+2
- Character Exhibits: 2
- Roguelite Shop: 23 items, including a Quest Board with 30 Quests.

- 角色卡牌：73+2
- 角色展品：2
- Roguelite 商店，內含 23 個商品，其中包括擁有 30 個任務的任務欄。

## Also / 還有

Bug reports, suggestions are appreciated. For feedback, post your suggestions in the modding channel in the Lbol discord.

有 bug，提議可以在 QQ 官方群聯繫 `@L大`，或在 Discord 官方群的#mod-discuss 裡 `@Lvalon` 。
