## Mima / 魅魔

Mima character mod.

魅魔角色模组。

## Btw / 但又話說回來了

After transitioning from v1 Mima to v2, she now provides a relatively more proper power scaling experience, and is available in beta.

經過初代魅魔的洗禮後，二代魅魔對比下終於擁有對比下符合正常的強度遞增體驗，可供玩家體驗 beta 版本了。
